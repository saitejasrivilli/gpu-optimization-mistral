How the Fleet Document System Works

How a Query Gets Answered

When you ask a question, the system follows this flow to find the answer in either the database, documents, or both.

Three Types of Questions

The system automatically routes your question to the right data source.

📊 Database Only

Example: "How many trucks do we have?"

Uses fleet database (trucks, drivers, maintenance records). 100% accurate because data is in structured database.

📄 Documents Only

Example: "What was the oil change cost for T-084?"

Searches ingested documents (fuel receipts, maintenance invoices, inspection reports, registrations).

🔗 Both (Hybrid)

Example: "Show T-084 with maintenance history and costs"

Combines database facts with document details for complete picture. Links are based on truck ID extracted from documents.

Data Pipeline

How documents become searchable, linked data.

System Components

What each piece of the system does.

🧠 LLM (DeepSeek)

Converts natural language to SQL, generates answers, verifies grounding

🗄️ Fleet Database

SQLite with trucks, drivers, maintenance records, documents metadata

📄 Document Store

Ingested PDFs/images with extracted text, indexed by truck/driver ID

🔗 Entity Linker

Extracts truck IDs (T-084) and driver IDs (D-001) from document text

✅ Grounding Verifier

Confirms answers are based on actual data, prevents hallucinations

🔍 Vector Search

Semantic search using sentence embeddings to find relevant documents
